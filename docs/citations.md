# Citations

References for every method this package implements or drives are collected in
[`CITATIONS.bib`](https://github.com/LouieSlocombe/openmmnqe/blob/main/CITATIONS.bib),
grouped by the part of the package each method belongs to.

Cite the entries for the code path you actually ran: a plain MM production run
needs far less than an RPMD study with OPES on a path collective variable and a
MACE potential.

Reaction paths (NEB, transition states, IRC), the collective variables, the
ORCA interface and free-energy-surface plotting live in
[reactiontools](https://github.com/LouieSlocombe/reactiontools) — see its
`CITATIONS.bib` for those. Ligand parameterisation runs through
[forcefill](https://github.com/LouieSlocombe/forcefill), and the GAFF, AM1-BCC
and SMIRNOFF references it relies on are kept here.
